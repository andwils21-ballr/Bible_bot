# Bible_bot

A close rendering of the Ethiopian Orthodox Tewahedo canon into English — 89
books, 1,554 chapters — aiming at the intent, tone, and context the source
actually carries, with notes on what English normally loses.

Built chapter by chapter by scheduled Claude Code sessions. A Routine fires
every 5 hours, picks up where the last one stopped, renders the next few
chapters, and pushes.

## Layout

```
manifest.json        the canon: 89 books, order, chapter counts, source tier
RENDERING_SPEC.md    the style contract every session obeys — read it first
books/<n>-<slug>/    one Markdown file per chapter (01.md, 02.md, ...)
docs/                the reading website (GitHub Pages serves this folder)
docx/                printable Word files, one per book (not committed)
build_site.py        books/ -> docs/     (stdlib only)
build_docx.py        books/ -> docx/     (needs: pip install python-docx)
PROGRESS.md          what's done, regenerated by progress.py
```

Markdown is the single source. The website and the Word files are both built
from it, so nothing is ever typed twice and nothing can drift.

## Reading it

```
python3 build_site.py
```

Then serve `docs/` (`python3 -m http.server -d docs`) or turn on GitHub Pages
→ Settings → Pages → Branch `main`, folder `/docs`. Books run down the left
rail; click one for its chapters; click a chapter to read it. Verse numbers are
clickable anchors, so any verse can be linked directly.

## Printing it

```
pip install python-docx
python3 build_docx.py           # all books
python3 build_docx.py matthew   # one book
```

## Source tiers

`manifest.json` marks every book with how honestly it can be rendered:

| tier | meaning | books |
|---|---|---|
| `primary` | worked from the Hebrew, Aramaic, or Greek | 73 |
| `secondary` | no source-language access; worked from established English translations, and said so in the notes | 7 |
| `none` | no usable source text — gets a `(NEED SOURCE TO TRANSLATE)` stub, never a guess | 9 |

The tier system exists because the failure mode of this project is fluent
invention that reads exactly as authoritative as real work. A stub is the
honest output when there is nothing to translate from.
