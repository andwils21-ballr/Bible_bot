# Word review: blight, detestable, loathsome

Built 2026-09-23 for Andrew. Every verse rendered so far that contains each Hebrew word, as it reads now,
with the word the Greek (Septuagint, Swete) and Latin (Vulgate, Clementine) use in the same verse. Delete this file when done.

## What the other languages show

- ***tsara'at***: the Greek uses one word, *lepra*, in every verse, for skin,
  clothing (13:47) and house walls (14:34) alike, and the Latin copies it
  (*lepra*). *Lepra* is built on the Greek word for a scale or flake, so it
  describes how the thing looks, not a named disease. The English "leprosy" comes
  from it but now means Hansen's disease, a different thing. **No ancient version uses a
  disease word that could also apply to a wall.** That supports one word
  throughout, and it has to fit cloth and walls, which "disease" cannot.
  The surprise: **the Greek of Exodus 4:6 has no such word at all**. It reads
  *his hand became like snow*. Only the Hebrew and Latin say what it became.
- ***to'evah* and *sheqets***: the Greek uses the **same word, *bdelygma***, for
  both. The Latin scatters them: *abominatio*, *execratio*, *profanum* and
  *detestantur* for *to'evah*; *abominabile*, *execrabile*, *immundus* and
  *polluere* for *sheqets*. **Neither version keeps the two apart; only the
  Hebrew does.** In the Hebrew, *to'evah* is used of people and practices a
  community will not have among it, and *sheqets* of animals and food.
- **Leviticus 7:21 is confirmed.** The Greek reads *any unclean abomination*
  (*bdelygma*), which matches *sheqets*, not "swarming thing." It sits at Greek 7:11 because the
  Greek numbers this chapter ten verses differently.
